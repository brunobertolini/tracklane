`tln` is an ESM-only TypeScript library published to npm as
[`@brunobertolini/tln`](https://www.npmjs.com/package/@brunobertolini/tln).

## Quick start

```ts
import { format } from '@brunobertolini/tln';

format('  hello  ', { prefix: '> ' }); // '> hello'
```
